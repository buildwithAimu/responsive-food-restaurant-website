# MyOnlineMeal - Food Delivery Website

A responsive food delivery service website built with pure HTML and CSS.
Clean UI with smooth scrolling and modern layout.

## ✨ Features
- 🧭 Sticky navigation bar with hover effects
- 🍔 Services section (Catering, Bulk Ordering, Food Ordering)
- 🤝 Clients showcase section
- 📬 Contact form
- 📱 Fully responsive design
